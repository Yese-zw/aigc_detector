构建下一代 AI 服务应用

采用与管理端一致的清爽浅色系、蓝紫渐变和卡片化布局，让 API 文档页视觉更统一、信息更聚焦、开发接入更高效。

认证授权

所有接口请求必须在 HTTP Header 中包含有效 API Key。未授权或额度不足的请求将被拒绝。

HTTP 请求头注入 
X-API-Key: your_live_api_key_here

获取专属 API Key，请联系管理员或在控制台生成。

基础消耗原则

  • 文本改写按请求消耗的字符长度计费。
  • 特定改写组合 ID 可能触发双倍计费。
  • 仅请求成功后才扣除额度。
风格对齐说明：本页已采用管理端同款圆角卡片、浅色渐变和主色按钮/标签体系，便于前后台体验统一。

查询余额

查询当前 API Key 账户中剩余可用点数（字符数）。

GET /ai/quota

请求说明

该接口仅需携带有效 X-API-Key 即可访问，不扣除额度。

Request 
curl -X GET "https://api.lingsiai.cn/ai/quota" \
  -H "X-API-Key: your_api_key"
Request 
import requests

url = "https://api.lingsiai.cn/ai/quota"
headers = {
    "X-API-Key": "your_api_key"
}

response = requests.get(url, headers=headers)
print(response.json())
Response (200 OK) 
{
  "status": "success",
  "result": {
    "quota": 9986
  },
  "message": null,
  "quota_info": {
    "used": 0,
    "remaining": 9986
  }
}

文本改写

提供智能文本改写服务，提升文本质量并增强拟人化表达。

POST /ai/AIRewrite

请求参数 (JSON)

参数名 描述
text 必填 string
待改写的源文本内容
combination_id 必填 integer / string
改写组合 ID，可在支持列表获取。部分组合可能触发双倍额度消耗。
Request 
curl -X POST "https://api.lingsiai.cn/ai/AIRewrite" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "这段文字需要被智能化地改写。",
    "combination_id": "10030"
  }'
Request 
import requests

url = "https://api.lingsiai.cn/ai/AIRewrite"
headers = {
    "X-API-Key": "your_api_key",
    "Content-Type": "application/json"
}
data = {
    "text": "这段文字需要被智能化地改写。",
    "combination_id": "10030"
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
Response (200 OK) 
{
  "status": "success",
  "result": {
    "rewrite_text": "在智能技术的处理下，这段话需要进行改写。"
  },
  "message": null,
  "quota_info": {
    "used": 14,
    "remaining": 9986
  }
}
