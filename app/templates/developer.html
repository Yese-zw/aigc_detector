AI 服务应用

通过我们高性能、高可用性的接口服务，轻松将智能文本处理能力集成到您的平台中。

认证授权

所有的接口请求都必须在 HTTP Header 中包含有效的 API Key。未授权或额度不足的请求将被拒绝。

HTTP 请求头注入 
X-API-Key: your_live_api_key_here

获取您的专属 API Key，请联系管理员或在控制台中生成。

基础消耗原则

  • 文本改写按请求消耗的字符长度计费。
  • 特定的改写组合 ID 可能会双倍计费。
  • 每次请求成功后才会真正扣除额度。

查询余额

查询当前 API Key 账户中剩余的可用点数（字符数）。

GET /ai/quota

请求说明

调用该接口只需携带有效的 X-API-Key 即可进行访问，不扣除额度。

Request 
curl -X GET "https://api.lingsi.chat/ai/quota" \
  -H "X-API-Key: your_api_key"
Request 
import requests

url = "https://api.lingsi.chat/ai/quota"
headers = {
    "X-API-Key": "your_api_key"
}

response = requests.get(url, headers=headers)
print(response.json())
Response (200 OK) 
{
  "status": "success",
  "result": {
    "quota": 9986
  },
  "message": null,
  "quota_info": {
    "used": 0,
    "remaining": 9986
  }
}

文本改写

提供智能文本改写服务，提升文本质量或使其更加拟人化。

POST /ai/AIRewrite

请求参数 (JSON)

参数名 描述
text 必填 string
待改写的源文本内容
combination_id 必填 integer / string
选定的改写组合ID。
取值可在【支持列表】接口中获取。部分特定组合ID可能会消耗双倍额度。
Request 
curl -X POST "https://api.lingsi.chat/ai/AIRewrite" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "这段文字需要被智能化地改写。",
    "combination_id": '10030'
  }'
Request 
import requests

url = "https://api.lingsi.chat/ai/AIRewrite"
headers = {
    "X-API-Key": "your_api_key",
    "Content-Type": "application/json"
}
data = {
    "text": "这段文字需要被智能化地改写。",
    "combination_id": 10030
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
Response (200 OK) 
{
  "status": "success",
  "result": {
    "rewrite_text": "在智能技术的处理下，这段话需要进行改写。"
  },
  "message": null,
  "quota_info": {
    "used": 14,
    "remaining": 9986
  }
}
